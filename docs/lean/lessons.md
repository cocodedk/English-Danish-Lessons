- The builder's first Bash call, a chain of commands that also read files outside its worktree, was refused, and it took that to mean Bash was denied for the whole run and wrote the whole feature without running anything. Bash is allowed for single plain commands: try `bash /tmp/graph-gates/<spec>.sh` (the gate) or `npm run verify` on its own before giving up, and use Read for files outside the worktree (spec 01, run 3, 2026-09-30).
- A test helper that reads files with `new URL(`../../${path}`, import.meta.url)` fails under Vite: it rewrites that pattern and the path becomes `undefined` (`src/test/undefined`). Read with `node:fs` and a path relative to the project root instead (Vitest runs from the root), e.g. `readFileSync('src/styles/tokens.css', 'utf8')`. Vitest also returns an empty string for a `?raw` CSS import unless `test.css` includes `/\?raw/` in `vite.config.ts`; reading from disk avoids the question (spec 01, run 3, 2026-09-30).
